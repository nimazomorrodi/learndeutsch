# Lernhaus

اپ یادگیری آلمانی برای اجرای شخصی روی مک. PHP صفحهٔ ورود و API پیشرفت را اجرا می‌کند و از طریق PDO به MySQL وصل می‌شود. جاوااسکریپت تعامل‌های درس و تمرین را در مرورگر انجام می‌دهد. CSS تولیدشدهٔ Tailwind، فونت و تصویرها داخل پروژه هستند.

## اجرای محلی

روی این مک فایل `Start Lernhaus.command` را باز کن و به [میز مطالعه](http://127.0.0.1:4876/) برو. در اولین اجرا، راه‌انداز دیتابیس و جدول‌ها را می‌سازد و درس‌ها را وارد می‌کند. صفحهٔ ورود پیوند «ساخت حساب» دارد. برای عوض کردن حساب، از پایین سایدبار وارد «حساب من» شو و «خروج از حساب» را بزن.

راه‌انداز از PHP با افزونه‌های `pdo_mysql` و `mbstring` و MySQL Server محلی استفاده می‌کند. وب‌سرور روی آدرس loopback اجرا می‌شود و MySQL یک سوکت یونیکس خصوصی دارد. بستن پنجرهٔ ترمینال یا زدن Ctrl+C وب‌سرور را متوقف می‌کند. برای توقف دیتابیس اختصاصی این پروژه، از همین پوشه `php bin/stop-db.php` را اجرا کن. اجرای دوبارهٔ راه‌انداز داده‌های حساب‌ها را حفظ می‌کند.

## داده‌ها

- جدول‌های `levels` و `lessons` محتوای مشترک سطح‌های A1 تا B1 شامل گرامر، لغات، مثال‌ها و سؤال‌ها را نگه می‌دارند. منبع اولیهٔ درس‌ها `database/curriculum.json` است.
- جدول `users` شامل نام کاربری ورود، نام نمایشی اختیاری و هش رمز عبور است. نام نمایشی از «حساب من» قابل ویرایش است. جدول `user_progress` برای هر کاربر یک رکورد دارد که محل ادامهٔ درس، بخش‌های تکمیل‌شده، روزهای مطالعه، کارت‌ها و نوبت مرور، پاسخ‌های آزمون جاری و نتیجهٔ آزمون‌ها را ذخیره می‌کند. نشست PHP حساب فعال را تعیین می‌کند. شمارهٔ نسخهٔ پیشرفت جلوی بازنویسی از یک تب قدیمی را می‌گیرد.
- دیتابیس و تنظیمات خصوصی در `.local/`، بیرون از ریشهٔ وب `dist/`، نگهداری می‌شوند. تغییر مرورگر یا پاک‌کردن کوکی‌ها با ورود دوباره به همان حساب قابل جبران است. انتخاب تم در همان مرورگر می‌ماند.

## انتقال سابقهٔ نسخهٔ قدیمی

پیش از شروع مطالعه با حساب جدید، «حساب من» را باز کن. اگر سابقهٔ شخصی نسخهٔ قبلی روی همین آدرس در مرورگر موجود باشد، دکمهٔ انتقال نمایش داده می‌شود. برای نسخه‌ای که با دوبارکلیک روی `dist/index.html` اجرا می‌کردی، همان فایل را در همان مرورگر باز کن، «دریافت فایل پیشرفت» را بزن و فایل را در «حساب من» انتخاب کن. در آدرس HTTP قدیمی هم `index.html?export` صفحهٔ دریافت را باز می‌کند، اگر فایل‌های محلی پروژه از همان آدرس سرو شوند.

## تغییر فرانت‌اند

قالب ورود در `app/views/auth.php` و صفحات مطالعه در `dist/app.js` و `dist/study-pages.js` هستند. برای بازسازی CSS پس از تغییر کلاس‌های Tailwind از پوشهٔ پروژه اجرا کن.

```sh
npm ci
npm run build:css
```

خروجی `dist/tailwind.css` همراه پروژه است و اجرای روزمرهٔ برنامه به Node.js نیاز ندارد.

## دیپلوی روی learn.nimazomorrodi.com

با هر پوش به `main` یا با **Actions → Deploy Lernhaus → Run workflow**، گیت‌هاب نصب دیتابیس را روی MariaDB آزمایشی بررسی می‌کند، تلفظ کارت‌ها را می‌سازد و از طریق SSH یک نسخهٔ تازه روی هاست می‌گذارد. اولین اجرا برای ساخت صداها زمان بیشتری می‌برد. دفعات بعد فایل‌های صوتی از کش بازیابی می‌شوند.

تنظیمات در **Settings → Environments → production** قرار دارند.

| نوع | نام | مقدار |
| --- | --- | --- |
| Secret | `DEPLOY_SSH_KEY` | کلید خصوصی اختصاصی که کلید عمومی آن در پنل SSH هاست ثبت شده |
| Secret | `DB_PASSWORD` | رمز کاربر دیتابیس مخصوص Lernhaus |
| Variable | `DB_NAME` و `DB_USER` | نام کامل دیتابیس و کاربر، با پیشوند حساب هاست |
| Variable | `DEPLOY_HOST`، `DEPLOY_PORT` و `DEPLOY_USER` | مشخصات اتصال SSH به سرور اصلی |
| Variable | `DEPLOY_KNOWN_HOSTS` | رکورد کلید عمومی میزبان در قالب OpenSSH و با پورت مقصد |
| Variable | `DEPLOY_WEBROOT` | پوشهٔ ریشهٔ وب ساب‌دامین نسبت به پوشهٔ حساب SSH، یا مسیر کامل آن |
| Variable | `DB_HOST` | آدرس دیتابیس، با پیش‌فرض `localhost` |

اکشن نسخه‌ها را در `~/.lernhaus/releases` می‌سازد و فایل‌های عمومی `dist` را از طریق لینک‌های نمادین در ریشهٔ ساب‌دامین ارائه می‌کند. تنظیمات دیتابیس بیرون از ریشهٔ وب است. نصب، جدول‌ها و محتوای درس‌ها را به‌روز می‌کند و حساب‌ها و پیشرفت موجود را حفظ می‌کند. پس از انتشار، اکشن شناسهٔ نسخه و صفحهٔ ورود را از طریق HTTPS بررسی می‌کند. اگر بررسی موفق نباشد، لینک نسخه به انتشار قبلی برمی‌گردد.

## صدای آلمانی

گفت‌وگوهای دونفره و پیام‌های شنیداری آزمون با دو صدای `F1` و `M1` مدل [Supertonic 3](https://huggingface.co/Supertone/supertonic-3) روی مک تولید شده‌اند. فایل‌های MP3 در `dist/assets/audio` همراه برنامه هستند و آفلاین پخش می‌شوند.

پس از تغییر متن در `database/curriculum.json` می‌توانی صدای همان درس را بازسازی کنی. این دستور را از پوشهٔ پروژه اجرا کن. اگر شناسهٔ درس را حذف کنی، صداهای همهٔ درس‌ها تولید می‌شوند.

```sh
.local/speech-venv/bin/python bin/generate-audio.py meinung
```

برای تولید دوباره روی یک مک دیگر، FFmpeg و بستهٔ پایتون `supertonic==1.3.1` لازم است. پوشه‌های `onnx` و `voice_styles` مدل را در `.local/supertonic-3` قرار بده یا مسیر آن‌ها را با گزینهٔ `--model-dir` مشخص کن.

در لایتنر، بلندگوی کنار واژه و بلندگوی کنار جمله جداگانه کار می‌کنند. اولین پخش، فایل صوتی را روی همین دستگاه می‌سازد و در `dist/assets/audio/leitner` ذخیره می‌کند. سمت آلمانی از Supertonic 3 و سمت فارسی از [صدای امیر برای Piper](https://huggingface.co/rhasspy/piper-voices/blob/main/fa/fa_IR/amir/medium/MODEL_CARD) استفاده می‌کند. برای آماده‌کردن صدای فارسی روی دستگاه دیگر، از پوشهٔ پروژه این دو دستور را اجرا کن.

```sh
.local/speech-venv/bin/python -m pip install piper-tts==1.8.0
.local/speech-venv/bin/python -m piper.download_voices --data-dir .local/piper fa_IR-amir-medium
```
